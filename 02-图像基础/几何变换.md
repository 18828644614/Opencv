# 几何变换

几何变换（geometric transformation）是改变图像中像素空间位置的一类操作。缩放会改变图像尺寸，旋转会改变像素的方向，平移会改变像素的位置，仿射和透视变换则可以把一个平面区域映射到另一个平面区域。

常用 API 可以先这样记：

| 任务 | API | 需要理解的内容 |
| --- | --- | --- |
| 缩放 | `cv::resize` | 输出尺寸、宽高比、插值 |
| 平移 | `cv::warpAffine` | 2×3 仿射矩阵、边界填充 |
| 旋转 | `cv::getRotationMatrix2D` + `cv::warpAffine` | 旋转中心、角度、画布是否裁剪 |
| 仿射变换 | `cv::getAffineTransform` + `cv::warpAffine` | 三组不共线点的对应关系 |
| 透视变换 | `cv::getPerspectiveTransform` + `cv::warpPerspective` | 四个角点、3×3 单应矩阵 |

几何变换最重要的不是背函数名，而是弄清楚这四件事：

1. 坐标中的 `x` 是列、`y` 是行；
2. 输出图像的宽高由 `dsize` 决定；
3. 输出像素通常需要通过插值从输入图像取值；
4. 图像上的文字、点、矩形框等标注也要同步变换。

## 1. 先理解图像坐标

### 1.1 `(x, y)` 与 `image.at(y, x)`

OpenCV 图像坐标的原点在左上角：

```text
(0, 0) ───────────────► x 增大
  │
  │
  ▼
y 增大
```

对宽为 `W`、高为 `H` 的图像：

- `x` 是列坐标，范围是 `0 ~ W - 1`；
- `y` 是行坐标，范围是 `0 ~ H - 1`；
- 左上角是 `(0, 0)`；
- 右下角是 `(W - 1, H - 1)`；
- `image.cols` 是宽度，`image.rows` 是高度。

坐标通常写成 `(x, y)`，但访问矩阵元素时是 `image.at(y, x)`：

```cpp
cv::Point2f point(100.0f, 50.0f); // x=100，y=50

// 对 CV_8UC1 图像，访问同一个位置时要先写 y，再写 x
uchar value = gray.at<uchar>(50, 100);
```

这两个顺序不要混淆：`cv::Point2f` 的构造函数使用 `(x, y)`，`Mat::at` 使用 `(row, column)`，也就是 `(y, x)`。

### 1.2 `Size` 的顺序是宽、高

`cv::Size` 和 `cv::Mat` 的尺寸查询使用宽在前、高在后：

```cpp
cv::Size outputSize(image.cols, image.rows); // width, height
int width = outputSize.width;
int height = outputSize.height;
```

例如：

```cpp
cv::Mat result;
cv::resize(image, result, cv::Size(640, 480));
```

这里得到的是宽 `640`、高 `480` 的图像，不是高 `640`、宽 `480`。而 `image.rows` 才是高，`image.cols` 才是宽。

## 2. 几何变换在做什么

可以把一张图像看成一个坐标网格。几何变换会把输入位置 `(x, y)` 映射到输出位置 `(x', y')`：

```text
输入坐标 (x, y) ──变换规则──► 输出坐标 (x', y')
```

不过实际生成图像时，OpenCV 通常采用“逆向采样”的思路来处理：

1. 先遍历输出图像中的每个像素 `(x', y')`；
2. 根据变换矩阵反推出它对应的输入位置 `(x, y)`；
3. 如果 `(x, y)` 不是整数，就用周围像素插值得到颜色；
4. 如果 `(x, y)` 超出输入图像边界，就使用边界模式填充。

这样做的好处是输出图像不会留下大量空洞。初学时不需要自己实现这个过程，但要理解它能解释两个常见现象：

- 变换后出现黑边，是因为输出位置映射到了输入图像之外；
- 图像变模或出现锯齿，是因为缩放或变换过程中发生了插值。

默认情况下，传给 `warpAffine` 或 `warpPerspective` 的矩阵表示“输入坐标到输出坐标”的变换，OpenCV 会在生成图像时内部进行反向查找。只有在明确使用 `cv::WARP_INVERSE_MAP` 时，才表示你传入的矩阵本身已经是“输出坐标到输入坐标”的逆矩阵。初学阶段通常不需要手动求逆，也不要随意添加这个标志。

## 3. 缩放：`cv::resize`

### 3.1 直接指定输出尺寸

```cpp
cv::Mat resized;
cv::resize(image, resized, cv::Size(800, 600),
           0.0, 0.0, cv::INTER_LINEAR);
```

参数含义如下：

```text
resize(src, dst, dsize, fx, fy, interpolation)
```

- `src`：输入图像；
- `dst`：输出图像；
- `dsize`：输出尺寸，顺序是 `width, height`；
- `fx`、`fy`：按比例缩放时使用的横向、纵向比例；
- `interpolation`：插值方式。

当 `dsize` 非空时，通常直接根据 `dsize` 确定输出尺寸：

```cpp
cv::resize(image, resized, cv::Size(640, 480));
```

### 3.2 按比例缩放

如果想保持原图宽高比，可以把目标宽度或高度按同一个比例计算：

```cpp
const int targetWidth = 800;
const double scale = static_cast<double>(targetWidth) / image.cols;
const int targetHeight = static_cast<int>(image.rows * scale);

cv::Mat resized;
cv::resize(image, resized,
           cv::Size(targetWidth, targetHeight),
           0.0, 0.0, cv::INTER_LINEAR);
```

也可以让 `dsize` 为空，直接使用 `fx`、`fy`：

```cpp
cv::Mat half;
cv::resize(image, half, cv::Size(), 0.5, 0.5, cv::INTER_AREA);
```

这里的 `cv::Size()` 表示没有直接指定目标尺寸。`0.5, 0.5` 表示宽和高都缩小为原来的一半。

如果强行把一个宽高比为 `4:3` 的图像变成 `1:1`，图像中的圆可能会变成椭圆，人或物体也会被拉伸。除非业务确实需要，否则应保持宽高比，或者使用“等比例缩放后填充/裁剪”的策略。

### 3.3 常用插值方式

插值解决的问题是：输出像素映射到输入图像的非整数位置时，应该如何估算颜色。

| 插值 | 常见用途 | 特点 |
| --- | --- | --- |
| `INTER_NEAREST` | 标签图、掩膜、像素画 | 只取最近像素，边缘容易有锯齿；不会产生新的标签值 |
| `INTER_LINEAR` | 普通缩放、旋转 | 速度和效果平衡，常用默认选择 |
| `INTER_CUBIC` | 放大照片 | 通常比双线性更平滑，但速度较慢 |
| `INTER_AREA` | 缩小照片 | 对降采样通常效果较好，可减少混叠 |
| `INTER_LANCZOS4` | 追求较高质量的放大 | 计算较慢，边缘附近可能出现轻微振铃 |

一个实用的选择原则：

- 普通彩色照片缩小：优先试 `INTER_AREA`；
- 普通照片旋转或一般缩放：使用 `INTER_LINEAR`；
- 二值掩膜、类别标签、实例 ID 图：使用 `INTER_NEAREST`；
- 不要用线性或立方插值缩放类别标签，否则可能生成原本不存在的中间类别值。

## 4. 平移：移动图像的位置

平移只改变位置，不改变图像的大小、方向和形状。平移公式是：

```text
x' = x + tx
y' = y + ty
```

其中 `tx` 是横向移动量，`ty` 是纵向移动量。OpenCV 的图像 `y` 轴向下，所以 `ty > 0` 表示向下移动。

### 4.1 使用 2×3 平移矩阵

平移矩阵写成：

```text
[ x' ]   [ 1  0  tx ] [ x ]
[ y' ] = [ 0  1  ty ] [ y ]
```

在代码中：

```cpp
const double tx = 80.0;  // 向右 80 像素
const double ty = 30.0;  // 向下 30 像素

cv::Mat translation = (cv::Mat_<double>(2, 3) <<
    1.0, 0.0, tx,
    0.0, 1.0, ty);

cv::Mat moved;
cv::warpAffine(image, moved, translation, image.size(),
               cv::INTER_LINEAR,
               cv::BORDER_CONSTANT,
               cv::Scalar(0, 0, 0));
```

`warpAffine` 的最后几个参数分别控制插值和边界填充。上面把移出原图范围的位置填成黑色。

### 4.2 输出尺寸决定是否保留空白区域

如果仍然使用 `image.size()` 作为输出尺寸，平移后超出右边或下边的内容会被裁掉。如果想让画布也变大，需要同时修改输出尺寸：

```cpp
const int extraRight = 80;
const int extraBottom = 30;
cv::Mat larger;
cv::warpAffine(image, larger, translation,
               cv::Size(image.cols + extraRight,
                        image.rows + extraBottom),
               cv::INTER_LINEAR,
               cv::BORDER_CONSTANT,
               cv::Scalar(30, 30, 30));
```

这里的 `dsize` 不是“变换矩阵推导出的自动尺寸”，而是你明确告诉 OpenCV 的输出画布大小。旋转、仿射、透视变换也遵循同样的规则。

## 5. 旋转：中心、角度和裁剪

旋转是初学者最容易得到“结果不完整”的变换。原因通常不是矩阵错了，而是输出画布仍然使用原图大小，旋转后的四个角超出了画布。

### 5.1 使用 `getRotationMatrix2D`

```cpp
const cv::Point2f center(image.cols / 2.0f, image.rows / 2.0f);
const double angle = 30.0; // OpenCV 定义为逆时针角度
const double scale = 1.0;

cv::Mat rotation = cv::getRotationMatrix2D(center, angle, scale);

cv::Mat rotated;
cv::warpAffine(image, rotated, rotation, image.size(),
               cv::INTER_LINEAR,
               cv::BORDER_CONSTANT,
               cv::Scalar(0, 0, 0));
```

`getRotationMatrix2D` 返回一个 `2×3` 的矩阵，包含旋转和缩放信息：

```text
[ x' ]   [ a  b  tx ] [ x ]
[ y' ] = [ -b a  ty ] [ y ]
```

它会自动把旋转中心 `center` 纳入平移项，因此不要把“绕图像中心旋转”误写成只使用一个纯旋转矩阵。

OpenCV 文档把正角度定义为逆时针旋转。由于图像坐标的 `y` 轴向下，刚开始用坐标公式推导时可能觉得方向与数学课不同。实际调试时可以在图像中心画一个明显的箭头或文字，先用 `angle=30` 和 `angle=-30` 对照观察。

### 5.2 为什么旋转后会被裁剪

上面的代码输出尺寸仍然是 `image.size()`。当旋转后的图像比原画布更大时，超出的部分没有位置可放，只能被裁掉。

如果希望完整保留旋转后的图像，可以根据角度计算一个足够大的新画布：

```cpp
const cv::Point2f center(image.cols / 2.0f, image.rows / 2.0f);
cv::Mat rotation = cv::getRotationMatrix2D(center, 30.0, 1.0);

// 旋转矩阵的这两个值分别包含 cos 和 sin 的绝对影响
const double absCos = std::abs(rotation.at<double>(0, 0));
const double absSin = std::abs(rotation.at<double>(0, 1));

const int boundWidth = static_cast<int>(
    image.rows * absSin + image.cols * absCos);
const int boundHeight = static_cast<int>(
    image.rows * absCos + image.cols * absSin);

// 旋转中心原本在旧画布中心，现在把它平移到新画布中心
rotation.at<double>(0, 2) += boundWidth / 2.0 - center.x;
rotation.at<double>(1, 2) += boundHeight / 2.0 - center.y;

cv::Mat rotatedFull;
cv::warpAffine(image, rotatedFull, rotation,
               cv::Size(boundWidth, boundHeight),
               cv::INTER_LINEAR,
               cv::BORDER_CONSTANT,
               cv::Scalar(30, 30, 30));
```

这段代码有两个关键点：

1. 新宽高使用旋转后外接矩形的尺寸，而不是继续使用原图尺寸；
2. 计算完新画布后，要修改矩阵的平移项，把原旋转中心移动到新画布中心。

如果只计算 `boundWidth` 和 `boundHeight`，却不修正矩阵平移项，结果仍可能偏到画布外。

## 6. 仿射变换：用三点确定一个平面变换

仿射变换可以表示为：

```text
x' = a*x + b*y + tx
y' = c*x + d*y + ty
```

齐次坐标写法是：

```text
[ x' ]   [ a  b  tx ] [ x ]
[ y' ] = [ c  d  ty ] [ y ]
[ 1  ]   [ 0  0   1 ] [ 1 ]
```

在 OpenCV 中通常只保存左上角的 `2×3` 部分，所以使用 `warpAffine`。

### 6.1 仿射变换保持什么、改变什么

仿射变换可以组合平移、旋转、缩放、错切和翻转。它具有这些性质：

- 直线仍然是直线；
- 同一条直线上的点仍然共线；
- 平行线仍然平行；
- 长度、角度和矩形形状不一定保持；
- 不会表现出近处大、远处小的透视收缩。

例如，把一个矩形变成平行四边形可以用仿射变换；但如果要求纸张远端的边变短、平行边汇聚，就需要透视变换。

### 6.2 三组点确定仿射矩阵

`cv::getAffineTransform` 需要三组对应点：输入图像的三个点，以及输出图像中它们应该到达的三个点。

```cpp
std::vector<cv::Point2f> sourcePoints = {
    {0.0f, 0.0f},
    {static_cast<float>(image.cols - 1), 0.0f},
    {0.0f, static_cast<float>(image.rows - 1)}
};

std::vector<cv::Point2f> targetPoints = {
    {50.0f, 30.0f},
    {static_cast<float>(image.cols - 80), 60.0f},
    {80.0f, static_cast<float>(image.rows - 40)}
};

cv::Mat affine = cv::getAffineTransform(sourcePoints, targetPoints);

cv::Mat affineResult;
cv::warpAffine(image, affineResult, affine, image.size(),
               cv::INTER_LINEAR,
               cv::BORDER_CONSTANT,
               cv::Scalar(0, 0, 0));
```

这里最重要的不是点的具体数值，而是对应关系：

```text
sourcePoints[0] 对应 targetPoints[0]
sourcePoints[1] 对应 targetPoints[1]
sourcePoints[2] 对应 targetPoints[2]
```

两个数组的顺序一旦错位，矩阵仍然可能成功计算，但图像会发生意料之外的拉伸或翻转。三个源点不能共线，否则无法唯一确定一个二维仿射变换。

## 7. 透视变换：把倾斜平面拉正

透视变换也叫单应性变换（homography）。它适合处理同一个平面在不同视角下的投影，例如：

- 手机拍摄的倾斜文档拉正；
- 车道线或地面区域的俯视图；
- 把平面标志牌映射到正面模板；
- 进行四点透视裁剪。

### 7.1 透视矩阵和齐次坐标

透视变换使用 `3×3` 矩阵：

```text
[ x' ]   [ h11 h12 h13 ] [ x ]
[ y' ] = [ h21 h22 h23 ] [ y ]
[ w  ]   [ h31 h32 h33 ] [ 1 ]
```

实际输出坐标还要除以 `w`：

```text
X = x' / w
Y = y' / w
```

除以 `w` 正是透视变换可以让平行线在图像中汇聚、让远处物体看起来更小的原因。

代码中使用 `warpPerspective`，而不是 `warpAffine`：

```cpp
std::vector<cv::Point2f> sourceCorners = {
    {0.0f, 0.0f},
    {static_cast<float>(image.cols - 1), 0.0f},
    {static_cast<float>(image.cols - 1),
     static_cast<float>(image.rows - 1)},
    {0.0f, static_cast<float>(image.rows - 1)}
};

std::vector<cv::Point2f> targetCorners = {
    {80.0f, 40.0f},
    {static_cast<float>(image.cols - 60), 0.0f},
    {static_cast<float>(image.cols - 20),
     static_cast<float>(image.rows - 50)},
    {40.0f, static_cast<float>(image.rows - 20)}
};

cv::Mat perspective = cv::getPerspectiveTransform(
    sourceCorners, targetCorners);

cv::Mat perspectiveResult;
cv::warpPerspective(image, perspectiveResult, perspective,
                    image.size(),
                    cv::INTER_LINEAR,
                    cv::BORDER_CONSTANT,
                    cv::Scalar(0, 0, 0));
```

### 7.2 四个角点的顺序

四点透视变换最常见的约定是按轮廓顺序排列：

```text
0: 左上（top-left）
1: 右上（top-right）
2: 右下（bottom-right）
3: 左下（bottom-left）
```

源点和目标点都必须使用同一顺序。不要把点交叉连接，例如把左上、右下、右上、左下混在一起，否则会得到扭曲甚至翻折的结果。

用于文档矫正时，源点通常是原图中检测出的纸张四个角，目标点是一个规则矩形：

```cpp
const int documentWidth = 1000;
const int documentHeight = 1400;

std::vector<cv::Point2f> documentSource = {
    topLeft, topRight, bottomRight, bottomLeft
};
std::vector<cv::Point2f> documentTarget = {
    {0.0f, 0.0f},
    {static_cast<float>(documentWidth - 1), 0.0f},
    {static_cast<float>(documentWidth - 1),
     static_cast<float>(documentHeight - 1)},
    {0.0f, static_cast<float>(documentHeight - 1)}
};

cv::Mat homography = cv::getPerspectiveTransform(
    documentSource, documentTarget);

cv::Mat flatDocument;
cv::warpPerspective(documentImage, flatDocument, homography,
                    cv::Size(documentWidth, documentHeight));
```

这里的 `documentSource` 是原图中的四点，`documentTarget` 是输出图像中的四点。理解“源点到目标点”的方向，比死记某一组坐标更重要。

### 7.3 多于四组点时

四组点可以精确确定一个透视变换。如果有更多组匹配点，例如来自特征点匹配，可以使用 `cv::findHomography` 估计矩阵，并可使用 RANSAC 排除错误匹配：

```cpp
std::vector<cv::Point2f> manySourcePoints = {
    {0.0f, 0.0f}, {100.0f, 0.0f},
    {100.0f, 100.0f}, {0.0f, 100.0f},
    {50.0f, 50.0f}
};
std::vector<cv::Point2f> manyTargetPoints = {
    {10.0f, 20.0f}, {110.0f, 10.0f},
    {120.0f, 115.0f}, {5.0f, 105.0f},
    {60.0f, 60.0f}
};

cv::Mat homography = cv::findHomography(
    manySourcePoints, manyTargetPoints, cv::RANSAC);
```

这属于特征匹配和图像配准中的进阶内容。初学四点透视时，先确保四个点顺序和对应关系正确。

## 8. 插值与边界填充

### 8.1 边界填充

旋转、平移或透视后，有些输出像素可能映射到输入图像范围之外。`warpAffine` 和 `warpPerspective` 可以通过 `borderMode` 和 `borderValue` 指定如何处理：

```cpp
cv::warpAffine(image, result, matrix, outputSize,
               cv::INTER_LINEAR,
               cv::BORDER_CONSTANT,
               cv::Scalar(255, 255, 255)); // BGR 白色
```

常见模式如下：

| 模式 | 处理方式 | 适合场景 |
| --- | --- | --- |
| `BORDER_CONSTANT` | 使用固定颜色填充 | 明确需要黑边、白边或背景色 |
| `BORDER_REPLICATE` | 复制最近的边缘像素 | 不希望边缘突然出现黑色时可尝试 |
| `BORDER_REFLECT` | 镜像反射边缘 | 滤波、连续纹理类场景 |
| `BORDER_WRAP` | 从另一侧循环取值 | 周期性纹理，普通照片通常不使用 |

对于 `CV_8UC3` 图像，`cv::Scalar` 的顺序也是 B、G、R。`Scalar(0, 0, 255)` 是红色，不是蓝色。

### 8.2 图像和掩膜要使用不同的插值

如果同时变换原图和掩膜，应分别选择插值方式：

```cpp
cv::warpPerspective(colorImage, colorResult, homography, outputSize,
                    cv::INTER_LINEAR);

cv::warpPerspective(mask, maskResult, homography, outputSize,
                    cv::INTER_NEAREST);
```

对掩膜使用 `INTER_LINEAR` 会在 `0` 和 `255` 之间制造灰色边缘。对类别标签使用它则可能制造并不存在的类别编号。

## 9. 同步变换点、矩形框和检测结果

几何变换只作用于图像，不会自动更新你自己保存的标注。比如检测框原来包住一只猫，图像旋转后，旧坐标已经不再对应目标的位置。

### 9.1 变换点

仿射变换可以使用 `cv::transform`：

```cpp
std::vector<cv::Point2f> inputPoints = {
    {100.0f, 80.0f},
    {300.0f, 80.0f}
};
std::vector<cv::Point2f> outputPoints;

cv::transform(inputPoints, outputPoints, affineMatrix);
```

透视变换应使用 `cv::perspectiveTransform`：

```cpp
std::vector<cv::Point2f> outputPoints;
cv::perspectiveTransform(inputPoints, outputPoints,
                         perspectiveMatrix);
```

不要用 `cv::transform` 代替透视变换，因为透视矩阵包含齐次坐标除法。

### 9.2 变换轴对齐矩形框

一个检测框通常保存为 `x, y, width, height`。它不能只变换左上角和右下角，因为旋转或透视后，这两个点不一定仍然对应新矩形的左上和右下。更稳妥的做法是变换四个角点，再求新的外接矩形：

```cpp
cv::Rect box(100, 80, 200, 150);

std::vector<cv::Point2f> corners = {
    {static_cast<float>(box.x),
     static_cast<float>(box.y)},
    {static_cast<float>(box.x + box.width),
     static_cast<float>(box.y)},
    {static_cast<float>(box.x + box.width),
     static_cast<float>(box.y + box.height)},
    {static_cast<float>(box.x),
     static_cast<float>(box.y + box.height)}
};

std::vector<cv::Point2f> transformedCorners;
cv::perspectiveTransform(corners, transformedCorners,
                         perspectiveMatrix);

cv::Rect newBox = cv::boundingRect(transformedCorners);
```

注意：`newBox` 是轴对齐外接框，可能比真正变换后的四边形更大。如果后续任务支持旋转框或四边形，最好保留 `transformedCorners`，不要过早转换成普通矩形。

## 10. Windows 优先的完整示例

下面的程序一次演示缩放、平移、保留完整画布的旋转、仿射变换和透视变换，并把结果保存到 Windows 路径下。

### 10.1 准备目录和图片

先准备一张图片，例如：

```text
D:\learn\Opencv\data\sample.jpg
```

如果 `data` 目录不存在，可以在 PowerShell 中创建：

```powershell
New-Item -ItemType Directory -Force D:\learn\Opencv\data | Out-Null
New-Item -ItemType Directory -Force D:\learn\Opencv\output | Out-Null
```

把自己的 JPG 或 PNG 图片复制为 `sample.jpg`。代码中的 Windows 路径使用 C++ 原始字符串：

```cpp
R"(D:\learn\Opencv\data\sample.jpg)"
```

这样反斜杠不需要写成两次。如果使用普通字符串，则必须写成：

```cpp
"D:\\learn\\Opencv\\data\\sample.jpg"
```

### 10.2 `geometry_demo.cpp`

```cpp
#include <opencv2/opencv.hpp>

#include <cmath>
#include <filesystem>
#include <iostream>
#include <string>
#include <vector>

namespace fs = std::filesystem;

int main() {
    const std::string inputPath =
        R"(D:\learn\Opencv\data\sample.jpg)";
    const fs::path outputDir = R"(D:\learn\Opencv\output)";

    fs::create_directories(outputDir);

    cv::Mat image = cv::imread(inputPath, cv::IMREAD_COLOR);
    if (image.empty()) {
        std::cerr << "无法读取图片：" << inputPath << '\n'
                  << "请确认文件存在，并检查路径和当前权限。\n";
        return 1;
    }

    if (image.cols < 200 || image.rows < 200) {
        std::cerr << "示例要求输入图片至少为 200 x 200 像素。\n";
        return 1;
    }

    std::cout << "输入尺寸：" << image.cols << " x " << image.rows
              << " (width x height)\n";

    // 1. 缩放：等比例缩小到原来的 60%
    cv::Mat resized;
    cv::resize(image, resized, cv::Size(), 0.6, 0.6,
               cv::INTER_AREA);

    // 2. 平移：向右 60 像素、向下 40 像素，画布保持原大小
    const cv::Mat translation = (cv::Mat_<double>(2, 3) <<
        1.0, 0.0, 60.0,
        0.0, 1.0, 40.0);
    cv::Mat translated;
    cv::warpAffine(image, translated, translation, image.size(),
                   cv::INTER_LINEAR, cv::BORDER_CONSTANT,
                   cv::Scalar(0, 0, 0));

    // 3. 旋转：绕中心旋转 30 度，并扩大画布避免裁剪
    const cv::Point2f center(image.cols / 2.0f,
                             image.rows / 2.0f);
    cv::Mat rotation = cv::getRotationMatrix2D(center, 30.0, 1.0);

    const double absCos = std::abs(rotation.at<double>(0, 0));
    const double absSin = std::abs(rotation.at<double>(0, 1));
    const int rotatedWidth = static_cast<int>(
        image.rows * absSin + image.cols * absCos);
    const int rotatedHeight = static_cast<int>(
        image.rows * absCos + image.cols * absSin);

    rotation.at<double>(0, 2) +=
        rotatedWidth / 2.0 - center.x;
    rotation.at<double>(1, 2) +=
        rotatedHeight / 2.0 - center.y;

    cv::Mat rotated;
    cv::warpAffine(image, rotated, rotation,
                   cv::Size(rotatedWidth, rotatedHeight),
                   cv::INTER_LINEAR, cv::BORDER_CONSTANT,
                   cv::Scalar(30, 30, 30));

    // 4. 仿射变换：三组不共线点一一对应
    const float width = static_cast<float>(image.cols - 1);
    const float height = static_cast<float>(image.rows - 1);

    std::vector<cv::Point2f> affineSource = {
        {0.0f, 0.0f},
        {width, 0.0f},
        {0.0f, height}
    };
    std::vector<cv::Point2f> affineTarget = {
        {40.0f, 30.0f},
        {width - 60.0f, 70.0f},
        {80.0f, height - 40.0f}
    };

    const cv::Mat affine = cv::getAffineTransform(
        affineSource, affineTarget);
    cv::Mat affineResult;
    cv::warpAffine(image, affineResult, affine, image.size(),
                   cv::INTER_LINEAR, cv::BORDER_CONSTANT,
                   cv::Scalar(0, 0, 0));

    // 5. 透视变换：把四个角映射到一个梯形
    std::vector<cv::Point2f> perspectiveSource = {
        {0.0f, 0.0f},
        {width, 0.0f},
        {width, height},
        {0.0f, height}
    };
    std::vector<cv::Point2f> perspectiveTarget = {
        {80.0f, 40.0f},
        {width - 50.0f, 0.0f},
        {width - 20.0f, height - 40.0f},
        {40.0f, height - 10.0f}
    };

    const cv::Mat perspective = cv::getPerspectiveTransform(
        perspectiveSource, perspectiveTarget);
    cv::Mat perspectiveResult;
    cv::warpPerspective(image, perspectiveResult, perspective,
                        image.size(), cv::INTER_LINEAR,
                        cv::BORDER_CONSTANT,
                        cv::Scalar(0, 0, 0));

    const bool ok =
        cv::imwrite((outputDir / "resized.png").string(), resized) &&
        cv::imwrite((outputDir / "translated.png").string(), translated) &&
        cv::imwrite((outputDir / "rotated.png").string(), rotated) &&
        cv::imwrite((outputDir / "affine.png").string(), affineResult) &&
        cv::imwrite((outputDir / "perspective.png").string(),
                    perspectiveResult);

    if (!ok) {
        std::cerr << "至少一个结果保存失败："
                  << outputDir.string() << '\n';
        return 1;
    }

    cv::imshow("original", image);
    cv::imshow("resized", resized);
    cv::imshow("translated", translated);
    cv::imshow("rotated", rotated);
    cv::imshow("affine", affineResult);
    cv::imshow("perspective", perspectiveResult);

    std::cout << "结果已保存到：" << outputDir.string() << '\n'
              << "按任意键关闭窗口...\n";
    cv::waitKey(0);
    return 0;
}
```

代码中的透视示例把原图矩形映射成梯形，便于观察效果。真正做文档矫正时，通常反过来：把原图中检测到的纸张四边形作为 `perspectiveSource`，把规则矩形作为 `perspectiveTarget`。

.\build\Release\geometry_demo.exe

## 11. 常见错误与排查顺序

### 11.1 宽高写反

错误示例：

```cpp
cv::resize(image, result,
           cv::Size(image.rows, image.cols));
```

这里把高当成了宽、把宽当成了高。应使用：

```cpp
cv::Size(image.cols, image.rows);
```

### 11.2 旋转结果只剩一部分

通常是因为 `warpAffine` 的输出尺寸仍然是 `image.size()`。确认是否需要计算旋转后的外接矩形，并同步修正旋转矩阵的平移项，参见“旋转：中心、角度和裁剪”。

### 11.3 四点顺序错了

透视变换的源点和目标点必须一一对应，并按同一方向排列。推荐固定使用：

```text
左上 -> 右上 -> 右下 -> 左下
```

不要按“离原点最近”“数组输入顺序随便”来排列。

### 11.4 把仿射当成透视，或者反过来

- 三点、不要求平行线汇聚：使用 `getAffineTransform` + `warpAffine`；
- 四点、平面矫正、需要透视收缩：使用 `getPerspectiveTransform` + `warpPerspective`。

### 11.5 直接变换矩形的两个角

旋转和透视会让轴对齐矩形变成四边形。应变换四个角点，再用 `boundingRect` 求外接矩形；如果业务需要精确边界，则保存四边形点。

### 11.6 对掩膜使用了线性插值

掩膜和类别标签是离散值，缩放或变换时应使用 `INTER_NEAREST`。彩色图像才通常使用 `INTER_LINEAR` 或 `INTER_AREA`。

### 11.7 路径正确但图片仍然读不到

按这个顺序检查：

1. 是否调用了 `image.empty()`；
2. 文件扩展名和实际格式是否一致；
3. Windows 路径是否使用了原始字符串，或正确写成了双反斜杠；
4. `output` 目录是否存在且有写入权限；
5. PowerShell 当前目录是否和你以为的目录一致；
6. CMake 是否链接到了正确的 OpenCV 安装。

## 12. 一页速记

```text
坐标：Point(x, y)，x 向右，y 向下
访问：image.at(y, x)，先行后列
尺寸：Size(width, height)，宽在前，高在后

缩放：resize
平移：warpAffine + 2x3 矩阵
旋转：getRotationMatrix2D + warpAffine
仿射：三组不共线点 + getAffineTransform
透视：四组对应角点 + getPerspectiveTransform

彩色图：通常用 INTER_LINEAR 或 INTER_AREA
掩膜/标签：使用 INTER_NEAREST
黑边/白边：通过 borderMode 和 borderValue 控制
检测框：变换四个角点，不要只变换两个角点
```
