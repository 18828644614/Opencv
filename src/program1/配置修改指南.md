## 文件说明

## 换新路径时的修改步骤

### 情况1：OpenCV安装在不同位置

假设你的OpenCV现在在 `E:/MyLibs/opencv`

**修改CMakeLists.txt第42行：**
```cmake
set(OpenCV_DIR "E:/MyLibs/opencv/build")
```

**修改build.ps1第75行（提示信息）：**
```powershell
Write-Host "`n运行前请确保将 E:\MyLibs\opencv\build\x64\vc16\bin 添加到PATH环境变量"
```

**运行时设置PATH：**
```powershell
$env:Path += ";E:\MyLibs\opencv\build\x64\vc16\bin"
```

---

### 情况2：项目移动到新目录

假设你把整个project1文件夹复制到 `E:/Projects/MyOpenCVApp`

**不需要修改任何配置文件！**

只需要确保：
1. CMakeLists.txt中的OpenCV_DIR指向正确的OpenCV路径
2. opencv.cpp中的图片路径是绝对路径或相对于exe的路径

---

### 情况3：重命名程序/源文件

假设你想改名：
- 可执行文件：`opencv_test` → `my_app`
- 源文件：`opencv.cpp` → `main.cpp`

**修改CMakeLists.txt第57和62行：**
```cmake
add_executable(my_app main.cpp)
target_link_libraries(my_app ${OpenCV_LIBS})
```

**修改build.ps1第72行提示信息：**
```powershell
Write-Host "`n编译完成！可执行文件位于: build\Release\my_app.exe"
```

---

### 情况4：添加多个源文件

假设你的项目现在有：
- main.cpp
- image_utils.cpp
- filters.cpp

**修改CMakeLists.txt第57行：**
```cmake
add_executable(opencv_test main.cpp image_utils.cpp filters.cpp)
```

或者更清晰的写法：
```cmake
set(SOURCES
    main.cpp
    image_utils.cpp
    filters.cpp
)
add_executable(opencv_test ${SOURCES})
```

## 编译流程说明

### 完整编译命令
```powershell
# 1. 进入项目目录
cd D:\learn\Opencv\src\program1

# 2. 设置PATH（临时，每次新开PowerShell都需要）
$env:Path += ";D:\opencv\opencv\build\x64\vc16\bin"

# 3. 编译
powershell -ExecutionPolicy Bypass .\build.ps1

# 4. 运行
.\build\Release\opencv_test.exe
```

### build.ps1做了什么
```
1. 删除旧的build目录
2. 创建新的build目录
3. 进入build目录
4. 运行cmake配置（生成Visual Studio项目文件）
5. 运行cmake编译（调用MSVC编译器）
6. 返回上级目录
7. 显示完成信息
```

### 目录结构
```
program1/
├── opencv.cpp          # 源代码
├── CMakeLists.txt      # CMake配置
├── build.ps1           # 编译脚本
└── build/              # 编译生成目录（自动创建）
    ├── *.vcxproj       # Visual Studio项目文件
    ├── Release/        # Release版本输出
    │   └── opencv_test.exe
    └── Debug/          # Debug版本输出（如果编译Debug）
        └── opencv_test.exe
```

## 常见路径格式

### CMakeLists.txt中（使用正斜杠）
```cmake
set(OpenCV_DIR "D:/opencv/opencv/build")
set(OpenCV_DIR "C:/Program Files/opencv/build")
set(OpenCV_DIR "E:/Libraries/OpenCV-4.12.0/build")
```

### PowerShell中（可以用反斜杠或正斜杠）
```powershell
$env:Path += ";D:\opencv\opencv\build\x64\vc16\bin"
$env:Path += ";C:/opencv/opencv/build/x64/vc16/bin"
```

### C++代码中（Windows推荐用原始字符串）
```cpp
// 推荐：原始字符串（不需要转义）
const std::string path = R"(D:\images\test.jpg)";

// 或者：使用正斜杠
const std::string path = "D:/images/test.jpg";

// 避免：双反斜杠（容易出错）
const std::string path = "D:\\images\\test.jpg";
```

## Visual Studio版本对照

| Visual Studio版本 | 生成器名称 | vc目录 |
|------------------|-----------|--------|
| VS 2022 | "Visual Studio 17 2022" | vc16或vc17 |
| VS 2019 | "Visual Studio 16 2019" | vc16 |
| VS 2017 | "Visual Studio 15 2017" | vc15 |
| VS 2015 | "Visual Studio 14 2015" | vc14 |

**注意：** OpenCV预编译版通常标注vc16，但VS 2022也兼容

## 故障排除

### 问题：找不到OpenCV
```
CMake Error: Could not find OpenCV
```
**解决：** 检查CMakeLists.txt中的OpenCV_DIR路径是否正确

---

### 问题：运行时找不到DLL
```
无法启动此程序，因为计算机中丢失opencv_world4120.dll
```
**解决：** 
```powershell
$env:Path += ";D:\opencv\opencv\build\x64\vc16\bin"
```
或永久添加到系统环境变量

---

### 问题：中文乱码或编译错误
```
error C2001: 常量中有换行符
```
**解决：** 确保CMakeLists.txt中有：
```cmake
if(MSVC)
    add_compile_options(/utf-8)
endif()
```

## 实用技巧

### 1. 永久添加OpenCV到PATH（避免每次设置）

**方法1：系统环境变量**
1. 右键"此电脑" → 属性 → 高级系统设置
2. 环境变量 → 系统变量 → Path → 编辑
3. 添加：`D:\opencv\opencv\build\x64\vc16\bin`

**方法2：PowerShell配置文件**
```powershell
# 编辑配置文件
notepad $PROFILE

# 添加这行
$env:Path += ";D:\opencv\opencv\build\x64\vc16\bin"
```

### 2. 快速清理编译结果
```powershell
Remove-Item -Recurse -Force build
Remove-Item *.png
```

### 3. 编译Debug版本（用于调试）
修改build.ps1第63行：
```powershell
cmake --build . --config Debug
```
可执行文件在 `build\Debug\opencv_test.exe`

### 4. 创建新的OpenCV项目
```powershell
# 复制这三个文件到新项目目录
Copy-Item CMakeLists.txt 新项目目录/
Copy-Item build.ps1 新项目目录/
# 创建新的cpp文件
# 修改CMakeLists.txt中的源文件名
```
