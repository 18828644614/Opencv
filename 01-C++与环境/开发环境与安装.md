# 开发环境与安装

## 推荐组合

- Windows：Visual Studio 2022 + CMake
- Linux：GCC/Clang + CMake
- IDE：Visual Studio、CLion 或 VS Code
- OpenCV：4.x

## 验证安装

先确认能找到 OpenCV 的 CMake 配置目录，再构建一个最小程序。不要只把 DLL 复制到某个目录；运行时路径、编译时头文件和链接库必须对应同一套版本。

## 常见检查

- `opencv2/opencv.hpp` 是否能被找到
- CMake 是否找到 `OpenCVConfig.cmake`
- Debug/Release 库是否混用
- DLL 是否在 PATH 或可执行文件旁边
